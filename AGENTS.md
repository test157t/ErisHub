# Agent Guidelines
- Follow the Repository Rules strictly: no fallback, redundant, duplicate, or legacy code.
- Replace old behavior directly.
- If a change seems to require compatibility handling, stop and ask for clarification before proceeding.

## Decision Making
- Prioritize simplicity and directness.
- Eliminate rather than accommodate legacy patterns.
- Default to asking for clarification when requirements conflict with repository rules
- Never introduce fallback, redundant, duplicate, or legacy compatibility codes.
